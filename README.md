
### You will need the following:

- https://www.gitpod.io
- This Repo
- LineageOS 16.0 repo Manifest
- https://github.com/LUSD-Samsung-Custom-Roms/Gitpod-Rom-Builder.git

To initialize your local repository using my trees, use a command like this:
```
repo init -u https://github.com/LUSD-Samsung-Custom-Roms/android.git -b lineage-16.0 --git-lfs
```
Then to sync up:
```
repo sync
```
